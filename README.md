# ProTap Club

NFC tag reader/writer for Android and iOS. Read tags, and write URLs, text, contacts, social profiles, call-to-action links, or reset a tag.

| | Folder | Requirements |
|---|---|---|
| Android | `android/` | Android Studio, target SDK 36, min SDK 21 |
| iOS | `ios/` | Xcode 26, iOS 18+, iPhone with NFC, Apple Developer Program team (NFC Tag Reading capability) |

Release signing keys are not part of this repository.
